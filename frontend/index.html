ABOUT AUTOVALUE

How AutoValue Works

AutoValue is a machine learning based used-car price prediction system. It analyzes important vehicle characteristics and estimates the expected price of a used car.

01

Vehicle Information

The user enters the car model, company, manufacturing year, kilometres driven, fuel type and ownership information.

02

Data Processing

The input values are converted into the format required by the machine learning pipeline. Categorical values such as company, model and fuel type are encoded.

03

Machine Learning Model

AutoValue uses a trained Linear Regression model to learn the relationship between vehicle characteristics and historical car prices.

04

Ownership Adjustment

The application applies an ownership-based adjustment to the model's base prediction before displaying the final estimated price.

05

Final Price

The processed vehicle information is passed to the model and the resulting estimated price is displayed to the user.
