ABOUT AUTOVALUE

How AutoValue Works

AutoValue is a machine learning based used-car price prediction system. It analyzes important vehicle characteristics and estimates the expected market price of a used car.

01

Vehicle details are collected from the user.

02

ML Prediction

04

Final Price

The estimated price is adjusted and displayed.

System Workflow

The complete process behind the AutoValue prediction system.

01

Vehicle Information

The user provides important information about the vehicle including the car model, company, manufacturing year, kilometres driven and fuel type. Ownership information is also collected because the number of previous owners can affect the resale value of a used vehicle.

02

Data Preprocessing

Before prediction, the input data must be converted into the same format used during model training. Numerical features such as year and kilometres are passed as numerical values, while categorical features such as company, model and fuel type are encoded for the machine learning model.

03

Machine Learning Model

AutoValue uses a trained Linear Regression model. The model learns relationships between vehicle characteristics and historical used-car prices. During prediction, the trained model receives the processed vehicle information and generates a base estimated price.

04

Ownership Adjustment

A used car with more previous owners can have a different resale value. AutoValue therefore applies an ownership-based adjustment to the base prediction. First Owner has no reduction, while subsequent ownership levels receive the configured reduction.

05

Price Prediction

After preprocessing and model inference, the system calculates the final estimated price. The result is then returned by the FastAPI backend and displayed through the AutoValue interface.

06

User Interface

The frontend provides a simple interface for entering vehicle information, requesting predictions and viewing previous predictions. The frontend communicates with the FastAPI backend through REST API endpoints.
